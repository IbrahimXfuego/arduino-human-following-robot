# Publish with drag and drop

1. Extract `Arduino-Human-Following-Robot.zip`.
2. On GitHub create a **Public** repository named `arduino-human-following-robot`.
3. Suggested description: `Arduino Uno target-following robot with ultrasonic scanning, IR steering, SG90 pan servo and L293D motor control.`
4. Leave GitHub's generated README/.gitignore/license options empty initially; the package already has project files.
5. Choose **uploading an existing file**, or **Add file → Upload files**.
6. Open the extracted project folder and drag its **contents** into the uploader. README.md must be at the repository's main level, not inside an extra outer folder.
7. Commit with `Add Arduino human-following robot code and documentation`.
8. Check the README and wiring image. Preserve CREDITS.md and the inspiration link.
9. Add your actual photos/videos and keep component details current.
10. Add the real repository URL to your portfolio.

Do not upload only the ZIP. Keep any generated executable/temporary files out of the upload; browser drag-and-drop does not apply .gitignore filtering. Choose a license separately if you want to grant open-source reuse rights.

Suggested topics: `arduino`, `arduino-uno`, `robotics`, `human-following-robot`, `ultrasonic-sensor`, `l293d`, `embedded-cpp`.
