## Arduino Human-Following Robot

A four-wheel Arduino robot using a servo-mounted ultrasonic sensor and two IR sensors for nearby-target following.

- Built a four-wheel chassis around Arduino Uno and an L293D motor shield.
- Used an SG90-mounted ultrasonic sensor for a startup sweep and distance sensing.
- Combined proximity sensing and differential motor control to follow at a target gap.
- Stopped the robot when the target was lost.

Technology tags: Arduino Uno, Embedded C++, L293D, HC-SR04-compatible ultrasound, IR sensors, SG90, motor control.

Credit the inspiration repository: https://github.com/vermaPrateek10/Human-Following-Robot
